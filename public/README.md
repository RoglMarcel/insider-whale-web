# Public Assets Directory

Place static assets here that should be served at the root of the application.
Vite copies all files in this folder to the build output directory (`dist`) as-is.

## Starting Animation
Place your video file here and name it **`intro.mp4`**:
* File Path: `c:\Users\8marc\Desktop\Insider\public\intro.mp4`

The terminal is configured to look for `/intro.mp4` on startup, play it full-screen, and then automatically fade out and transition into the main terminal interface when finished (or when skipped).
